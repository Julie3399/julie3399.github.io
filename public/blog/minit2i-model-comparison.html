MiniT2I Food LoRA Comparison

Base Model

MiniT2I is a minimalist text-to-image generation model introduced by Xianbang Wang, Hanhong Zhao, Yiyang Lu, Kangyang Zhou, Linrui Ma, and Kaiming He. The project is from Kaiming He’s research group at MIT CSAIL; the public project entry was submitted on June 13, 2026, with open code, model checkpoints, and training recipes.

The official code and checkpoints are released under the MIT License. Useful links: blog, paper / project entry, Hugging Face checkpoint, and JAX code.

MiniT2I generates images directly in RGB pixel space. Its recipe uses a pixel-space MM-JiT denoiser trained with flow matching and conditioned on frozen FLAN-T5-Large text features, while avoiding image tokenizers, cascaded generation, RL stages, and auxiliary losses. In this comparison, we use MiniT2I-B/16 as the base model.

Model Size

1.03 GBMiniT2I-B/16 base transformer checkpoint
57.86 MiBour food LoRA adapter
~1.09 GBbase transformer + LoRA adapter

MiniT2I-B/16 has 258M image-model parameters plus a 341M frozen text encoder. Our LoRA adds 15.16M trainable parameters. The adapter file is 57.86 MiB, roughly 5% of the base transformer checkpoint size. At inference time, the fine-tuned model is loaded as the 1.03 GB base transformer plus the 57.86 MiB LoRA adapter, so the combined image-model checkpoint footprint is about 1.09 GB. The frozen text encoder is shared and is not changed by LoRA.

LoRA Adaptation

We fine-tune MiniT2I with LoRA instead of retraining the full model. LoRA keeps the original model frozen and learns small low-rank adapter matrices inside selected linear layers, making the update lightweight, portable, and easy to load on top of the base checkpoint. Our adapter uses rank 32 and targets attention, MLP, and text-projection related modules.

Training Dataset

We used Epicure MCP to help create a recipe-photo dataset for LoRA fine-tuning. Epicure is an ingredient-embedding model that supports science-backed flavour pairing, cuisine-aware recipe design, and structured food prompt generation. We used Gemini for image generation.

The final dataset contains 1,000 food-photography examples with structured prompts covering dish name, cuisine or cultural origin, dish type, visible ingredients, and composition style. We curated the images for visual consistency, excluding overhead views and keeping 513 table-level low-angle images and 487 angled 3/4-view images.

The dataset was balanced mainly by cuisine and course. Cuisine distribution: Western 350, Asian 350, Other/Fusion 130, Latin 100, and Middle Eastern / North African 70. Course distribution: main/other 571, dessert 160, soup/stew 71, noodle/pasta 67, salad 61, starter 48, drink 16, and breakfast 6.

Training used short captions combining dish name, cuisine style, dish type, visible ingredients, and visual constraints such as professional food photography, soft natural light, no text, and no people.
